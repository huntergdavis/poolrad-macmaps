# 0.74.0 — Keep restored games with the right notebook

F35 resolves a save's campaign before restoring it. Missing or deleted notebook
pairings offer **Create separate notebook and load** or **Cancel load**.
Existing notebooks stay intact, and a new pairing is remembered for later loads.

Notebook recording pauses during the transition. Native restore completion
activates the prepared notebook; rejection returns to the previous one.
Interrupted transitions leave recording unavailable until a notebook is chosen.
Truncated native bodies are refused before any machine fields are applied.

638 Java tests and the universal Android build passed. Live checks covered
cancel, creating a notebook, repeated loads, existing bindings, and native
rejection with the original game and notebook preserved. Original notebook
files remained byte-identical when a separate campaign was created.
No physical-tablet retest is claimed. F97's disk-content safety audit remains open.
