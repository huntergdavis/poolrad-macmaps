# 0.37.0 — Whose turn it is

- **The acting character is marked.** In a battle the companion rings that
  character's marker on the overview and puts a bar down the left edge of their
  row in the party list. The game says whose turn it is in its own Combat
  Message window; the companion just puts it where you are already looking.
- **A "T" when a character can train.** The game's own experience threshold for
  one of their classes has been passed — no more speculative walks to the
  training hall.
- **An "R" when spells are waiting on rest.** Somebody memorised spells that
  still need sleep, so you know whether making camp will actually achieve
  anything.

Neither mark is advice. The app is not telling you to train or to rest, only
that the game would let you.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.37.0/poolrad-macmaps-0.37.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
those are still not included.
