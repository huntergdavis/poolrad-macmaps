# 0.32.0 — A Return key where your thumb already is

- **A ⏎ button in the bottom-right corner of the map.** Most of Pool of Radiance
  plays with the mouse, but not all of it, and opening the whole keyboard to
  press one key is a poor trade. Same size and same generous touch target as the
  footprints and fog buttons.

It presses exactly the key the app's on-screen keyboard presses — it is a
shortcut, not a new way into the game.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.32.0/poolrad-macmaps-0.32.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
those are still not included.

Next: the per-character Quick toggle. The game has no menu for one, so it needs
writing a byte into the running game — which you asked for, and which is being
built narrowly and with the flag located from a real battle first.
