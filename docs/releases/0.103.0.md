# 0.103.0 — Skip informational messages

Options now has **Auto-skip informational messages**, off by default. Turn it
on to dismiss supported informational acknowledgements automatically.

Story/tutorial Continue prompts, choices and confirmations stay manual, so
turning it on never chooses an answer or advances a story script for you.
Unknown dialogs and save/load errors also stay visible.

Verified live with the option on and off, including story prompts and
confirmations that remain manual.

[Detection and verification](../AUTO_SKIP_MESSAGES.md).
