# 0.70.0 — Ten quick saves, with pictures

- **Quick save keeps your last ten snapshots. Quick load restores the latest.**
  **Load…** lists all saves with terse dates, times and the actual guest screen
  captured with each save. Tap for a larger
  preview, Load, or Delete; the picker stays above the game. Old saves without
  previews still load. Named saves and autosaves have their own histories.
- **Q remembers your request.** If the character's Quick toggle cannot be
  applied yet, it waits for a validated party frame. A small dot marks a pending
  change; tapping again reverses it. Party reorder cannot redirect the request
  to another character, and loading a state clears pending changes.
- **Game-file backups moved to Settings.** The PoolRad menu stays focused on
  play. Find the existing backup/restore tool under Settings → Back up / restore
  game saves…; unsafe restart-based Load has not returned.

The existing fast reference/diff save format is unchanged. Only a small bounded
screen copy is added at capture; image compression and storage run off-thread.
Tests cover ten-slot rotation, timestamp collisions, failed writes, legacy
slots, preview failure, notebook links and overlapping save requests.

Verified with **632 unit tests**, seven native checks, Android PNG tests and
live emulator save/restore, history rollover, menu and preview checks.

**Disk safety is still an open investigation.** These snapshots do not include
disk images. They cannot guarantee protection from a hard quit or restore disk
contents changed since capture. Keep independent backups and shut down the Mac
normally. The local play-test helper no longer force-stops a mounted guest.
This release has not been tested on a physical tablet.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.70.0/poolrad-macmaps-0.70.0.apk)
and install over the existing app. Bring your own ROM, Mac system and game;
none are included.
