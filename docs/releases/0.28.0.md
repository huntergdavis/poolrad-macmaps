# 0.28.0 — A switch for the footprints, and the party at any text size

- **A footprint button on the map.** Small, top-left, two soles when the trail
  is drawn and crossed out when it is not. The footprints can crowd a busy
  street, and now they go away with one tap — without opening Info. It is the
  same setting as the Info tab's checkbox, so the two always agree.
- **A very large system font no longer hides the party.** At a big accessibility
  text size a seven-member party wanted more room than the companion pane has,
  and the old answer was to draw no party at all. The party rows now shrink
  toward the ordinary size until they fit. The map's own labels are unchanged.
- **Every caption now ends in the build name**, e.g. `· v0.28.0`. A screenshot
  of the map now says which version drew it.

If the party still does not appear after installing this, the caption will say
why in the pane itself: the pane's pixel size, its density and its text scale.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.28.0/poolrad-macmaps-0.28.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
those are still not included.
