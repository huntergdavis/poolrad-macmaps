# 0.10.0 — Know your party

Your map on the left; your companions on the right.

- Names, current/max HP, dark health bars, actual armor class and original
  monochrome class symbols, including combined symbols for multiclass heroes.
- Tap a row for a readable, explicitly labeled snapshot above the game.
  Unknown values stay unknown; this is not a character editor.
- The sidebar collapses when a narrow/short window or larger text would make
  it cramped. It never changes the space allocated to the Macintosh display.
- Fresh-save health now works: the reader understands the Mac allocator's
  legitimate padding instead of rejecting correctly sized character records.
- Existing combat filtering, immutable samples, stale-tap rejection, map flags,
  Map/Info tabs and offline references remain in place.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.10.0/poolrad-macmaps-0.10.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. Private bundled APKs stay local. Export your notebooks and
back up guest disks before uninstalling or clearing app data.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 75.
Same prototype signing key; source tag `v0.10.0`. The adjacent `.sha256` file
supplies the download checksum.

277 Java tests, 11 party and eight companion Android View checks, 54 Python
helper tests, 18 lifecycle/input checks and three native sanitizer suites pass.
The actual fresh SampleParty, negative-AC/multiclass details, keyboard collapse
and Info → Map restoration pass in the emulator. The in-place update preserves
the writable guest disk byte-for-byte. Join/leave regression coverage is
synthetic; broader live NPC and physical-device acceptance is not claimed.
