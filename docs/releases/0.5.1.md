# 0.5.1 — Hands-free code-wheel acceptance

The original Macintosh v1.1 game accepted two distinct automatic answers,
including after normal Quit → Finder → Open without restarting the emulator.
Loading the sample party afterward restored the live map, health strip and
existing map notes. No outside answer input or game-memory patch was used.

- Verified each letter before sending the next; exactly one Return per answer.
- Added focused regressions for all 13 answers, reused addresses on relaunch,
  and stale samples after submission. Debug logs identify the verified prompt.
- 152 Java tests and three native sanitizer suites pass; all 72 rune images
  remain bundled. No ROM, system disk or game assets are included in the APK.

Install `poolrad-macmaps-0.5.1.apk` **over the existing app** to retain notes.
Android 5.0+, Mac II, ARM64/ARMv7/x86/x86_64; versionCode 68, same prototype
signing key. [Setup guide](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/INSTALL.md).

Bring your own matching ROM, system and game. This is still an experimental
prerelease: other game versions, physical e-ink/stylus timing, and broader party
damage/healing remain unverified. Notebook export/import remains on the backlog.
[Detailed acceptance evidence](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/WHEEL_MEMORY.md).
