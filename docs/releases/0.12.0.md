# 0.12.0 — Follow your own footsteps

Your map remembers where you have actually been.

- Walked squares stay marked for each campaign notebook and verified area.
- Optional visited-only fog hides unvisited geometry; the full atlas stays the default.
- Little feet show recorded travel direction, not facing. Recent return
  directions disambiguate crossings; missing observations stay honest gaps.
- **Info → Exploration trail** controls fog, footprints and explicit per-area
  clearing. Clearing footsteps can retain coverage; neither action erases notes.
- Recording continues on Info or with the companion hidden while the app is
  resumed. Complete notebook backups now include exploration too.
- A read-only native movement gate prevents camp/combat/loading coordinates
  from becoming fictional dungeon footsteps. No changes to the original game.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.12.0/poolrad-macmaps-0.12.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. The private bundled APK stays local. Keep your notebook and
guest-disk backups before uninstalling or clearing app data.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 77.
Same prototype signing key; source tag `v0.12.0`. The adjacent `.sha256` file
supplies the public download checksum.

325 Java tests, 32 actual Android View/software-Canvas checks, 54 Python helper
tests, 18 lifecycle/input checks and three native sanitizer suites pass.
Real Android verification covers observed eastward travel, fog, Info-tab
recording, separate Phlan/Slums coverage, area return, explicit clearing and
the old handwritten flag. An Android-created backup restores through the
production storage API with both area counts and the exact handwritten bytes.
The corrected APK retains earlier coverage across update and cold saved-game load.

Coverage starts with this version, not retroactively. It records sampled tile
occupancy, not line of sight or every instruction: slow or missing samples can
omit steps, and they are never interpolated. A reload does not roll back your
notebook's memory. Choose a separate notebook for a separate campaign. Backups
with exploration need 0.12.0 or newer; older backups still import.
