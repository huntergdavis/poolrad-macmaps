# 0.87.0 — Pick up the area's last note

Entering an identified map area automatically opens the note last used there.
A first visit opens a page on the arrival square. The selected square is
remembered separately for each campaign and area, including after app restart;
a deleted note falls back to the arrival square.

Reading pages follow area changes. Drawing, erasing, or changing a symbol pins
the current editor until Close & save, then opens the latest area's page.
An in-progress stroke stays intact, and ink saves to its original page.
Ordinary steps, camp and temporary unavailable readings do not reopen a closed
page. Note loading runs off the UI thread and discards outdated destinations.
Automatically opened pages leave game mouse/keyboard controls available;
Android Back saves and closes the page.

Verified on an Android emulator with real New Phlan–Slums gate crossings,
remembered ink on return, and controlled active-stroke/deferred-area checks.
See [behavior and verification](../AREA_NOTE_FOLLOW.md) for coverage and limits.
