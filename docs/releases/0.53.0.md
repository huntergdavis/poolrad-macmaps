# 0.53.0 — Where you were attacked

Wherever a fight starts, the map now keeps a struck-through creature on that
square.

Drawn from what happened to **this party** and nothing else: no bestiary, no
monster name, no count. A square where you were jumped once and a square where
you were jumped five times look the same — what the map is for is remembering
where the trouble is, not scoring it.

- **It is a fact about the place, not the walk.** Clearing your footprints keeps
  the marks, because forgetting the route is not the same as forgetting where
  you got ambushed.
- **It travels with the notebook.** The marks live beside the walked squares, so
  a backup carries them along with the rest of the map you drew.
- Below the size where the mark would be a smudge rather than a creature, it is
  not drawn.

## A detail worth knowing

The moment a fight begins is the *last* one where your own square is known —
combat takes the position away. So the square is read from the frame before
rather than the one that has just arrived.

## Your existing maps are safe

The stored format goes to version 2. **Version 1 records still load**, and read
as "no fights remembered here", which is the truth about them rather than a
loss. Refusing one would throw away a whole walked map over a feature it never
had.
