# 0.23.0 — The map says when you are searching

- While the game's own position line reads `search`, the companion's header
  appends one letter: `0, 4 W S`. It follows the exact bit the original tests
  before printing its own `" search"`, so it turns on and off with the game.
- The marker never appears without a verified position, and a search record the
  companion cannot read is reported as unreadable rather than as "not searching".
- **Fixes a map regression:** the companion's mode reader rejected the new
  packet outright, which blanked the whole area map — header, geometry, rulers
  and arrow. The map is back.
- **Fixes a crash:** a truncated sample threw instead of reading as unavailable.

Nothing in the game changes. The marker is read from the same memory the game
prints from; no rules, stats, coordinates or saves are touched.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.23.0/poolrad-macmaps-0.23.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. No game rules, stats or save formats change, and nothing is
written to guest memory.
