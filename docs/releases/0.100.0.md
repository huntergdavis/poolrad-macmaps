# 0.100.0 — Quiet while you read

The game now automatically goes idle while it is waiting for you, so reading
or writing a notebook page stops spending battery on an unchanged game.
Your next game action wakes it immediately. There is no new setting or paused
indicator, and your note and map stay visible.

The detector recognizes the game's untimed input loop rather than guessing
from a still screen. Timed activity continues normally. Emulator checks
confirmed zero guest CPU while reading and writing, followed by movement on
the first key press. [Detection and verification](../AUTOMATIC_IDLE.md).
