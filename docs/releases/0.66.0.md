# 0.66.0 — The game's message in larger type

**A new option mirrors the game's own message window in big, readable type over
the map.** 1984 Macintosh text at e-ink size is the hardest thing on the screen
to read; this puts the same words in a large card. Turn it on under
**Settings → View → Large message text** (off by default).

**How it works:** whatever the running game shows in its Message window is drawn
in an 18dp white card with a black border across the lower part of the map — the
same place the game keeps its own message — wrapped to fit, and hidden when there
is no message. Nothing is written to the game; it only mirrors what is already
there.

It is an option, not a default, because the card covers screen the map wants.

**Verified:** 607 Java tests, and the map render-check harness — the mirror
draws over the map, turning it off restores the map exactly, an empty message
draws no card, and a rendered image confirmed the large-type card.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.66.0/poolrad-macmaps-0.66.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
