# 0.36.0 — Dying and dead are different things

- **The map tells them apart.** A diagonal **✕** is someone still savable —
  unconscious or dying — and an upright **✝** is someone past saving. Two
  different shapes rather than the same one drawn heavier, so they read at a
  glance. The tally says which: "6 of yours · 6 others · 1 down · 1 lost".
- **The character list says the word.** Unconscious, Dying, Dead or Petrified,
  printed where the armour class usually sits, because armour class is the least
  interesting number about someone who is dying. It shows even in a narrow
  strip, where the class does not.

The app has had a one-letter badge for this for a while — `!` for dying, `X` for
dead — which is fine once you know it and no use at all when you are scanning
for who to go and bandage.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.36.0/poolrad-macmaps-0.36.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
those are still not included.
