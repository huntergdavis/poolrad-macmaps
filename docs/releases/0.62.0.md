# 0.62.0 — Auto-save while you play

**The companion now saves a state on its own, every few minutes, while a party
is in the world.** If something goes wrong, the last few minutes are waiting for
you under PoolRad → Save states.

**How it works:**

- Every five minutes, a whole-machine state is captured — the same safe save
  states this app already uses, so nothing restarts and the game never notices.
- Auto-saves are their own set, named by the time they were taken (in am/pm),
  and the newest 20 are kept — the oldest rotates out automatically.
- They never touch your Quick save or a save you named yourself.
- It only fires while a party is actually in the world, so it never wastes a
  slot on the boot screen or the Finder.

**Turn it off** any time under Settings → Control → Auto-save (it is on by
default).

**Verified:** 607 Java tests, the native build, the APK ABI check, and a live
run confirming the timer fires and correctly holds back when no party is loaded.
The rotation, naming, and exact round-trip are covered by unit tests, over the
same save-state engine shipped in the last releases.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.62.0/poolrad-macmaps-0.62.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
