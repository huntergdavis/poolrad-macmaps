# 0.24.0 — The journal list fills itself in

- When the running game names one of its own numbered references out loud, the
  selected notebook now records it under **Encountered in play**, once, tappable
  straight into your imported reference book.
- It reads the game's own Message window and matches **only wording that has
  actually been observed in the game** — today that is the tavern's
  `YOU OVERHEAR TAVERN TALE <n>`. Journal-entry and proclamation wordings have
  not been seen yet, so they are deliberately not recognised: a guessed pattern
  would quietly file a wrong number, and a wrong number is a spoiler.
- Anything uncertain records nothing. An unreadable or over-long sample is
  skipped rather than half-read, and a number your journal does not define is
  dropped.
- The list belongs to the notebook and travels in its backup. Notebooks written
  by earlier versions keep loading unchanged.

Nothing is written to the game, and no reference is opened for you; the list
only remembers what the game already said in front of you.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.24.0/poolrad-macmaps-0.24.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. Journal content is not included in the public APK.
