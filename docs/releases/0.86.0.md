# 0.86.0 — See the active save and the room left

F98 adds **Info → Saves**, a quick-glance page above the game. It names the
quick, named or automatic snapshot the game is running from (the one loaded,
or the manual save made since) with the time, or says plainly that this is a
normal Mac boot. A brand-new player sees "No saves yet".

Below that it counts stored saves by kind with their rotation limits (quick
keeps 10, automatic keeps 20, named stay until deleted), shows the bytes they
take, the device's free space, and roughly how many more saves fit at the
current average size. Under 64 MB free it says to delete old saves instead.
**Load…** on the page opens the existing picker, where Delete… cleans up.

Automatic saves count toward storage but never become the active save.
No guest state, disk image or snapshot format changes. The page refreshes once
a second while open and is bounded above the guest like Money.

Validation: 688 Java tests, including the new-player, long-history,
deleted-active-save, low-space and unknown-space texts and the folder usage
scan; universal Mac II build; live emulator acceptance of the page after a
quick save, after loading a named state, and with the save folder set aside
to reproduce a brand-new player. No physical-device acceptance is claimed.
