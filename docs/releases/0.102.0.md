# 0.102.0 — The game's own save prompts: nothing to answer

F36 asked whether the game still puts its save-and-overwrite questions in
front of the player on any companion path, and whether the companion should
answer them. It was checked, not built: no companion path reaches them.

Every save the companion makes (Quick save, named Save…, the five-minute
autosave, the fight-end quick save) and every restore is an emulator snapshot
that never touches a game menu. The only keys the companion ever sends are
the boot dialog's Return, the code-wheel answer, the character-sheet key the
player asks for and the selection click; the Cmd-key loader belongs to the
withdrawn restart-based loading and has no caller. Live on the emulator, a
Quick save and a Load of that save completed while the game screen stayed
untouched apart from the treasure pile's own animation.

The game's own prompts appear only when the player chooses File → Save
Current Game, Camp → Save or Quit, and those stay the player's to answer.
No code changed in this release; the backlog item is closed with the
evidence in docs/SAVE_STATES.md.
