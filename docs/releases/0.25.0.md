# 0.25.0 — See the whole battle at once

- When a fight starts, the companion now draws a **tactical overview**: one mark
  per combatant on the squares the game itself has placed them, your party
  filled and everyone else hollow, with the occupied area's corners named.
- The game's own Combat View stays where the fighting happens. The overview is
  reference only — nothing on it can be tapped, and it never suggests a move,
  names a monster, or shows anything the Combat View is not already showing.
- It appears only while a battle is actually running, and it clears the instant
  the battle ends. A sample the reader cannot fully verify draws nothing at all
  rather than a half-read battlefield.
- No terrain is drawn, because none has been decoded yet; the overview shows
  where everyone stands, not what they are standing on.

Read from the same table the game keeps for its own drawing, cross-checked
against the combat roster. Nothing is written to the game, and no rule, statistic
or save is touched.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.25.0/poolrad-macmaps-0.25.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
