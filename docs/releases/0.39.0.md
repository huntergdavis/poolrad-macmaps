# 0.39.0 — Fog and footprints, remembered per place

Clearing the fog in the slums because you have finished mapping them used to
clear it in the kobold caves as well, where you had not. Both switches are now
remembered **per area**.

- The two buttons in the corner of the map set the area you are looking at.
- An area you have never set them in uses the global answer, which is also the
  default a new area starts from — so somewhere new behaves the way you last
  chose rather than the way the app shipped.
- The Info dialog names the area it was opened from, and sets that area along
  with the default for the next one.
- **Your existing choice is kept.** The old preference becomes the global
  answer rather than being reset.

**Verified:** 465 Java tests including seven new ones for the per-area
resolution, five native probe suites, 14 render checks. Not verified here:
e-ink, stylus or on-device acceptance, which remain the owner's own.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.39.0/poolrad-macmaps-0.39.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
