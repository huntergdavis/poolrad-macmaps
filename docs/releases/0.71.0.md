# 0.71.0 — Select a character from the party pane

Tapping a character beside the map now also clicks that character in the
original game's Information window. The game selects who its character
commands act on, and the companion's details sheet remains available.

The target follows the guest window when it moves. A fresh party sample
resolves the requested character by name and class; missing or ambiguous
characters, covered/hidden windows and disabled selection are refused.
This uses ordinary mouse input and never writes the game's selection field.

Verification: 634 Java tests and native selection tests for moved windows,
occlusion, invalid memory, disabled input and reordered/ambiguous identities.
Live emulator verification is recorded in `docs/PARTY_SELECTION.md`.
This release has not been tested on a physical tablet.

Disk safety remains open under F97. Existing snapshots still do not rewind
guest disk contents; this feature makes no change to save-state safety.

Reusable developer helpers now cover fresh isolated test emulators,
documented guest Command-key input, core-status inspection, disassembly of
private CODE resources, and the per-feature release process. Private ROMs,
disks and extracted game data remain outside Git and the public APK.
