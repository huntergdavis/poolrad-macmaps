# 0.7.0 — Your personal starting point

An optional private build now starts with your own ROM and disks, without a
first-run import chore.

- Prepare a verified private package from your matching Mac II ROM and disk
  copies, then build `assembleMacIIPersonal` with its explicit input path.
- First launch verifies hashes, publishes a complete writable copy, selects
  the Mac II profile and boots. A combined System 7 disk with the existing
  startup alias opens the original game automatically.
- Existing imported media and later saves are never replaced. Switching to
  the ordinary public build keeps using the same installed disks.
- Setup failures offer Retry or the remembered normal file-import path.
  Recovery pages scroll, and re-opening during a copy does not block the UI
  on the installer's file-copy lock.

[Personal build guide](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/PERSONAL_PACKAGE.md)
· [Install guide](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/INSTALL.md).

**The public APK still includes no ROM, system, game or saves.** Private assets
are isolated to the personal build and must not be uploaded to public releases.
No runtime download, cloud service, game-stat edit or executable patch is added.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.7.0/poolrad-macmaps-0.7.0.apk)
and install over the existing app. Mac II universal, Android 5.0+,
ARM64/ARMv7/x86/x86_64, versionCode 72. Same prototype signing key; source is
tagged `v0.7.0`. Back up notebooks and guest disks before uninstall/clear-data.

213 Java tests, 16 synthetic package-builder tests and three native sanitizer
suites pass. Public APK checks reject private assets even after a personal
build. [Local acceptance and limits](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/LOCAL_TESTING.md).
Physical tablet, stylus and e-ink acceptance remain unperformed; no CI is claimed.
Known coverage gap: companion HP bars did not appear on the fresh SampleParty
used here, although the live map and original party display worked. The existing
party reader's fresh-save validation remains on the backlog.
