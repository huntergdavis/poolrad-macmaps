# 0.81.0 — Distinguish NPC companions

F67 adds an **NPC ·** prefix to NPC names in both party-row layouts, details,
marching order and accessibility actions. The original name remains unchanged
for character selection, combat matching and Quick toggles.

The missing field is now decoded: the original Macintosh game tests character
byte +0x87 above 127 both when appending “(NPC)” and when refusing to modify an
NPC. The companion reads that same flag from fully validated party records.
No guest data is written.

PRP9 uses one previously reserved header byte for the NPC mask without changing
packet size. Older packets remain supported with NPC status unknown. The
parser rejects flags outside the party count and preserves selected-character
information.

Validation includes 650 Java tests, native sanitizer tests covering all byte
values and masks, reordered identities and monster exclusion, plus Android
rendering of NPC labels in both layouts. NPC presentation uses synthetic
fixtures; no newly recruited live NPC or physical-tablet test is claimed.
See docs/NPC_MARKER.md for both original-code branches and coverage details.
