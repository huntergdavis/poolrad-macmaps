# 0.33.0 — Quick, per character, from the party list

- **A square Q on every character's row.** Filled when that character is on
  quick, outlined when they are not, and a question mark on the rare occasion
  the game's own flag does not read cleanly. Tap it to change it, from anywhere
  — no battle, no menu, no spacebar.

Pool of Radiance has no menu for this: its only Quick is the combat button, for
whoever's turn it is. So this one writes a single byte into the running game —
the same byte the game itself sets — which is the first time this app has
written anything to the game at all, and is there because you asked for it.

It is narrow on purpose. One byte, in one character record, and only after the
whole party has passed every check the app already makes before it will show you
a party at all. If the byte holds anything unexpected, nothing is written. The
readers are unchanged and still read-only.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.33.0/poolrad-macmaps-0.33.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
those are still not included.
