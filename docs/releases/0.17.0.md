# 0.17.0 — A copy you can go back to

- **Info → Save checkpoints** keeps explicit copies of one writable disk. Each
  copy is re-read after it is written and published only if its SHA-256 matches,
  so a copy that does not verify is discarded rather than listed.
- Every operation is refused while the emulator holds the disk. Save, restore
  and delete all take the same maintenance lease the desktop appearance tool
  uses, and the panel tells you to quit the game and use the Mac's
  **Special → Shut Down** first.
- **A checkpoint is not an emulator save state.** It holds no RAM and no running
  game, so it cannot resume a turn or an unsaved position. Save inside the game
  first; the checkpoint then holds that save.
- Restoring replaces the whole disk, including every save inside it — and first
  checkpoints the disk as it stands, so it can always be undone. It is refused,
  leaving the live disk untouched, if the checkpoint no longer verifies, the new
  copy does not verify, or there is no free slot for the safety copy.
- Each entry records the file, size, digest, time, the last area the companion
  showed, the notebook and a small picture of that map. Those labels are
  companion history, not a position decoded out of the copied disk.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.17.0/poolrad-macmaps-0.17.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. Checkpoints live in the app's private storage and are removed
if you uninstall or clear its data; they are not part of a notebook backup and
never touch your original supplied files.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 83.
Same prototype signing key; source tag `v0.17.0`.

**385 Java tests** and **8 Android companion View checks** pass, as do the public
APK asset gate and signature verification. Verified live on a real 32 MiB disk:
the saved copy matched the live disk byte-for-byte by independent `sha256sum`;
after a restart changed the disk, restoring returned it to the exact original
digest while the automatic safety copy held the changed state; and the restored
disk cold-booted with the campaign intact and no improper-shutdown notice.

The limits on checkpoint count and free space were exercised in tests rather
than by filling a device, and physical e-ink acceptance of this panel is
untested.
