# 0.116.0 — Battle map stays visible

Fixes a battle overview that could disappear with `Combat probe 7/0`. The
reader had required zero coordinates immediately after the last combatant,
although those bytes can be nonzero during a valid fight. It now reads only the
counted combatants and still checks each index, arena coordinate and the
independent combat roster before showing the map.

When a battle packet cannot be read, the map pane shows a short probe code to
help identify the cause. The corrected APK restored the battle map on the
owner's e-ink tablet on 2026-10-08. The native combat probe passed with
address and undefined-behavior sanitizers, and all 756 Java unit tests passed.
