# 0.114.0 — Keep the whole map in view

Larger parties now use compact, one-line rows automatically when that keeps
the party beside the map in one column. This gives the area and battle maps
back the width taken by a second party column. The option to use one-line rows
for every party size remains available.

Area and battle maps now fit above the bottom controls. When zoomed in, you
can drag the last row fully into view without the controls covering it.

Battle positions stay visible if an optional actor or enemy name cannot be
read. The combat packet clears incomplete enemy-name data, and the map keeps
independently valid character and enemy squares even when those labels are
invalid.

Verified with 753 Java unit tests, 28 party-pane Android View checks, 21
combat-overview View checks, exploration and combat zoom View checks, and
targeted native combat tests. The View checks used synthetic samples; the
specific live fight that exposed the missing markers was not available to
replay.
