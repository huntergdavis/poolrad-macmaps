# 0.45.0 — The map comes back on its own

Restarting the emulator used to leave the companion where it was until you
toggled its tab.

**The polling loop could die silently.** Two different things ended it the same
way: being told to stop, and finding the companion momentarily inactive —
mid-restart, or for an instant while the fragment is not resumed. The second
returned without scheduling the next tick, and nothing noticed. The loop was
simply gone.

Now a tick with nothing to read into waits and comes round again. Only being
told to stop actually stops it.

**And a machine coming up restarts the reading outright**, whether it is the
first one or a restart. Every held reading is dropped — a new machine is not a
blink — and the loop is started again rather than trusted to still be running.

**Verified:** 507 Java tests, six native probe suites, 25 render checks. The
original symptom was reported from the tablet and has not been reproduced here;
what has been fixed is a path in the loop that demonstrably ends it without
recovery, which matches the symptom exactly. Whether the tablet still needs a
tab toggle is the owner's check, as always.

and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
