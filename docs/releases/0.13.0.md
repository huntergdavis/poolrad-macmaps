# 0.13.0 — Follow the tour, spread out your notes

- Restore the opening tutorial map hidden by 0.12.0's movement guard. Rolf's
  story-menu stops and fully committed guided steps supply verified positions;
  observed adjacent steps can leave footprints. Story text no longer hides an
  independently verified position just because recording is temporarily paused.
- Give flag pages one compact title/tool row and a much larger sketch area.
  Pen, eraser, undo/redo, symbol, Fit page and Delete share the row; Close & save
  stays visible. Pen only and the per-note Save PNG action are removed.
- Explicit Camp, Combat, Wilderness and Loading / setup labels distinguish
  the last local reference map from live exploration. Party health stays
  independently sampled; non-local states cannot draw a false walking arrow.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.13.0/poolrad-macmaps-0.13.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. The personal bundled APK stays local. Updates retain your
writable disks, handwritten notes and exploration history.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 78.
Same prototype signing key; source tag `v0.13.0`. The `.sha256` asset verifies
the public download. Complete notebook backups remain available, as does the
full-screen screenshot tool.

340 Java tests, 33 Android View/software-Canvas checks, 54 Python helper tests,
18 lifecycle/input checks and three native sanitizer suites pass. The compact
editor's actual Android window measures 450 pixels of sketch height versus
213 previously at the tested tablet-sized viewport. See the linked local
acceptance record for the actual application-window and tour checks.

Footprints are sampled history, not an invented route between missed tiles.
General scripted relocations still break continuity, as do loads and non-local
modes. Dedicated tactical/wilderness maps remain separate work; wilderness
mode detection has original-code/synthetic coverage, not a live playthrough.
Physical e-ink/stylus behavior remains untested. No game rules, stats or saves
are edited by these features; no cloud service or LLM is involved.
