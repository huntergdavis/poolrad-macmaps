# 0.65.0 — One-line party rows for big parties

**A new option packs each party member onto a single line**, so a large party
keeps one column and the map keeps its full width. Turn it on under
**Settings → View → One-line party rows** (off by default).

**Why:** the normal two-line rows are roomy and fine for the usual six. But at
seven or eight members, or at a large font size, the sidebar needs two columns
and the map loses about a third of its width. Compact rows keep everything in
one column instead.

**What a one-line row shows:** the class icon, the name, current/max HP and
armour class on one line, with a thin health bar along the bottom edge. The
acting-character bar, the tapped-row highlight, the quick (Q) flag, and the T/R/W
marks are all still there.

Nothing changes unless you turn it on — the default two-line rows are untouched.

**Verified:** 607 Java tests, and the party-pane render-check harness — all 24
two-line checks unchanged, plus a new check proving an eight-member party that
needs two columns normally stays a single column in one-line mode, every row
drawn and tappable, with the map wider. Confirmed on a rendered image.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.65.0/poolrad-macmaps-0.65.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
