# 0.68.0 — Export your notes as a PDF

**Save all your notes to one PDF you can read or share anywhere.** In
**Info → Notes index**, tap **Export all notes as a PDF…** — every note becomes a
page, in the same area-and-date order as the index, and Android's save dialog
lets you keep it wherever you like.

Each page carries your handwriting for that square, with its area, tile, and the
date you drew it. (A note keeps your own ink; the game's map itself isn't stored,
so a page notes "map unavailable" — what you wrote is what's saved.)

**Verified:** 611 Java tests, and a live run — exporting a stored note produced a
valid one-page PDF whose page showed the handwriting under its area and tile.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.68.0/poolrad-macmaps-0.68.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
