# 0.95.0 — Sound off stops audio work

The original game's **Sounds** switch now stops sample synthesis, audio-buffer
transfers and the Android audio stream when off. **Walking Sounds** retains
its existing footstep behavior. No new UI or preference changes.

Muted audio stays off during System 7 background time slices. Sound-chip
status and interrupts remain correct, and re-enabling sound starts a fresh
stream without replaying muted audio.

Verified live: zero audio callbacks and no AudioTrack while muted, unchanged
native counters for 98 seconds, and output resumes when enabled. All 736 Java
tests and 25,600 native sound-state comparisons pass.
