# 0.8.0 — A quieter Mac desktop

**PoolRad → Desktop appearance** now changes the real Macintosh desktop,
without covering game windows or changing the game.

- Preview White, lightly stippled Mist, or monochrome Stonework.
- Save and quit the game, use Finder's **Special → Shut Down**, then apply
  the pattern and restart. Apply stays disabled while the guest is running.
- **Original** restores the first preserved desktop setting in the current
  disk; it never rolls campaign saves back to an older disk image.
- Changes are prepared on a copy and published atomically. Unsupported or
  unclean disks and corrupt setting backups are rejected without guesswork.

This first version supports the verified System 7.5.5 boot-disk layout, not
arbitrary Mac systems or wallpaper utilities. Original input files elsewhere
are untouched. [Desktop guide](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/DESKTOP_APPEARANCE.md).

Also includes the optional [pinned-source private build](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/PERSONAL_ASSET_FETCH.md)
introduced after 0.7.0. Explicitly configured assets can be fetched once and
reused from a verified offline cache. No default downloads or checkout hooks.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.8.0/poolrad-macmaps-0.8.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included in the public download. Private bundled APKs stay local.
Back up guest disks and notebooks before uninstalling or clearing app data.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 73.
Same prototype signing key; source is tagged `v0.8.0` and the adjacent
`.sha256` file supplies the APK checksum.

251 Java tests, 54 Python helper tests and three native sanitizer suites pass.
Both public/private APKs build; the public artifact contains the 72 bundled
runes and no private media. [Emulator acceptance and limits](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/LOCAL_TESTING.md).
Physical tablet, stylus and e-ink acceptance remain unperformed; no CI is claimed.
Fresh-save party HP coverage, Journal and companion tabs remain on the backlog.
