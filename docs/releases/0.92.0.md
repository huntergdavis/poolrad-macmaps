# 0.92.0 — Original tile size for the companion map

Info → Options now offers **Original area tile size (1:1)**: the game's
32-pixel tile spacing, with drag scrolling when the map does not fit. Fit to
screen remains the default. Notes, markers, exploration and discovered
connections remain available; tap the area header to find the party.

Verified on the emulator with scrolling, note reopening, area changes and
known-exit previews, plus persistence after restarting. All 725 Java tests and six Android viewport checks pass.
