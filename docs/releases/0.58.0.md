# 0.58.0 — Load withdrawn

**Loading a saved game from the companion is removed in this release.**

Loading had to close the running game and start the machine again, because the
game only offers *Load Saved Game* before a game begins. On at least one device
a restart did not come back cleanly and left the emulator wedged badly enough to
need a force-reboot. That is far too destructive to leave in front of anyone, so
the option is gone until the restart it depends on can be made reliable — or
replaced with an approach that does not restart the guest at all.

**What is untouched:** backing up your saved games to the app's storage, and
restoring them, both under **PoolRad → Saved games**. Those copy the save files
and never restart anything.

**Verified:** 586 Java tests, six native probe suites, 59 render checks, the APK
check.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.58.0/poolrad-macmaps-0.58.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
