# 0.98.0 — The whole combat arena

The battle overview now shows the original game's full **50 × 25-square
arena**, including empty space. Its frame stays fixed as combatants move or
fall, instead of resizing around occupied squares.

The bounds were decoded from the game's allocation and coordinate checks,
then confirmed against live combat memory. Verified on the emulator during
an actual fight: moving enemies, changing turns and fallen party markers
update inside the same arena. All 735 Java tests and the native boundary
checks pass; all 20 Android combat rendering checks passed.
