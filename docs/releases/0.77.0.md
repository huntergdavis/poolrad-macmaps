# 0.77.0 — Keep a message log with each notebook

F47 adds **Info → Message log**, with the latest 200 distinct observed
Message-window readings, newest first. It shows am/pm observation times and
marks truncated readings. Repeated polls add no duplicates; growing text updates
the current reading.

Each campaign keeps its own persistent history, included in notebook and
whole-companion backups. Recording pauses during snapshot campaign transitions.
Storage validates checksums, notebook identity and bounds; damaged records are
kept and reported. Existing backups without a log remain supported.

The universal Android build and 646 Java tests passed, including eight new
history/backup tests. All eight Android navigation checks passed. Live checks
verified two real game messages, deduplication, saved bytes/checksum, and
campaign isolation with history reloaded on return.

This records observed normal Message-window text, up to 512 characters per
reading; it can miss text replaced between polls and does not claim the separate
Combat Message window. No physical-tablet retest is claimed.

A reusable, OCR-guarded test-save loader replaces repeated manual test loading.
