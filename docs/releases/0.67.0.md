# 0.67.0 — A note index

**Every note you have left, listed in one place.** Open **Info → Notes index**
to see all your notes grouped by area, each with its square and the date you
made it (in am/pm). Tap one to read it.

Handwriting can't be searched, but now it can be listed — so a note you left in
Sokal Keep three sessions ago is one tap away, without walking back to find its
flag on the map.

Because a note is your own ink, it opens from anywhere — even for an area you
are not currently in (it just notes that the map snapshot isn't available).

**Verified:** 610 Java tests (new coverage for listing notes across areas and
naming areas from their stored ids), and a live run — the index listed a stored
note (New Phlan · Tile 11,2 · Sep 13, 11:01 PM) and opened its handwriting.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.67.0/poolrad-macmaps-0.67.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
