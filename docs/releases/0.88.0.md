# 0.88.0 — Remember where passages lead

Open **Connections**, beside **Map**, to see the areas your party has connected
through actual travel. Doors, stairs, teleports and scripted passages add arrows
only in directions traveled. Each recorded crossing keeps its departure and
arrival squares. Tap an area to browse its neighbors; **Current area** returns
to the party.

Connections are saved with the campaign notebook and included in notebook
backups. Loading a game save never discovers a connection. Unverified or missed
transitions are left unconnected, and unexplored destinations stay hidden.

Verified in the running game on the Android emulator: one gate crossing adds
one arrow, loading either area's save adds nothing, and walking back adds the
return arrow. All 702 Java tests and the native map/snapshot suites pass.
