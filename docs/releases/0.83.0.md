# 0.83.0 — Show the party's money

F46 adds actual holdings to **Info → Money**: each character's coins, gems and
jewelry, plus the party total and its exact gold equivalent. Gems and jewelry
remain counts, excluded from coin value because their appraisal is unknown.
Unreadable purses are marked unavailable and prevent a misleading partial total.

**Coin converter** opens the existing manual calculator. Money and Marching
order share a bounded, scrollable dialog with change-only refresh and lifecycle
cleanup. The new PRPA party packet preserves character selection and NPC labels.
No guest money, character data or disks are changed by this feature.

Validation: 663 Java tests; native sanitizer checks for all seven purse fields,
invalid counts, linked-list reorder and unchanged RAM; 28 Android party
rendering checks and nine companion navigation/layout checks. Live acceptance
matched the six-member party's seven gold and 26 platinum (137 gp), corroborated
Arax's purse against the original game sheet, and verified the converter and
Marching order. No physical e-ink or live NPC purse acceptance is claimed.

See docs/PARTY_MONEY.md for the original-game field evidence. README screenshots
are checked for freshness before release and refreshed from the published app.
