# 0.9.0 — A place for the companion

**Map / Info** tabs organize the space above the original Macintosh game.

- Map keeps the existing live map, flags and recognized party-health strip.
- Info groups Levels & skills, Spells, Weapons & armor, Money conversion and
  the illustrated Code wheel. Close a tool to return to Info.
- References and every rune/path picker fit the actual companion rectangle,
  even with the guest keyboard open. No game dimming or opening animation.
- PoolRad keeps Show companion, Notebooks, Screenshot and Desktop appearance;
  the five duplicate reference menu entries are gone.
- Hidden-map preferences migrate without changing your choice. Hide/show and
  saved state retain the selected tab; fresh sessions start on Map.
- Switching tabs does not restart or pause the Mac. Returning to Map requests
  fresh position/health samples; automatic code-wheel entry also works on Info.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.9.0/poolrad-macmaps-0.9.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. Private bundled APKs remain local. Back up your notebooks
and guest disks before uninstalling or clearing app data.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 74.
Same prototype signing key; source is tagged `v0.9.0` and the adjacent
`.sha256` file supplies the download checksum.

262 Java tests, ten companion lifecycle checks, eight Android View checks,
54 Python helper tests, eight stopped-core input checks and three native
sanitizer suites pass. Both APK variants build; the public one contains all
72 rune illustrations and no private media.
