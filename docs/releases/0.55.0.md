# 0.55.0 — The party heading says what is outstanding

**PARTY · TAP FOR DETAILS** told nobody anything. It now reads

> **1 down · 2 hurt · 1 can train**

when any of that is true, and falls back to the old wording when none of it is.

Every fact in it was already on screen — a `T` here, a word there, a bar shorter
than it was — and every one is easy to miss when six rows compete for a glance.
The line answers the question you actually have between fights: **is there
anything to deal with before moving on?**

- **Ordered by how much it matters**, not by how the record is laid out.
  Somebody dying is not a footnote to somebody's spell slots.
- **Somebody down is not also counted as hurt.** They are on nought hit points,
  which is hurt by any measure, but saying both would count one person twice.
- **It reports; it does not advise.** "2 can train" is a fact about what the game
  will allow, not a suggestion to walk to the training hall.

It is in the accessible text too, ahead of the per-character detail.

**Verified:** 581 Java tests including eight new ones, six native probe suites,
58 render checks. One existing render check needed widening — a condition change
is now *meant* to rewrite the heading, so the heading band is excluded from the
region that must stay identical. Everything below it still has to stay put.
