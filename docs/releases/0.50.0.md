# 0.50.0 — How much of this area is done

The map header now carries the fraction beside the area's name — **New Phlan ·
62/256**.

A count of walked squares was a number with no scale. Every local area is
sixteen squares by sixteen, so the fraction answers the question a mapper
actually has: is there much left?

- It appears only once there is something to report.
- **Never over a reference map.** When the party is elsewhere and the map is
  being shown for reference, its coverage belongs to where the party actually
  is, not to the place you are looking at.
- The accessible text reads "62 of 256 squares walked" rather than "62 walked
  squares" — a sentence, with the same scale.

The percent form rounds **down** on purpose. 255 squares out of 256 is not a
hundred percent, and a progress figure that says it is would be a small lie at
exactly the moment somebody is deciding whether to stop exploring.
