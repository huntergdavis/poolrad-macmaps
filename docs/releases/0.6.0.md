# 0.6.0 — Keep your cartography

Your handwritten campaign maps now have proper local backups.

- **PoolRad → Notebooks:** back up a campaign to `.prnb`, restore it, or
  deliberately remove it after confirmation.
- Backups preserve every area's flags, symbols, editable strokes and original
  campaign identity. Restore validates the whole file and never overwrites an
  existing notebook or silently switches campaigns.
- **Save PNG** on a flag page exports the full fitted map and handwriting at
  1600×768, with notebook, area, tile and symbol in the heading.
- Cancel/failure feedback makes clear whether an external file was saved;
  original notes stay intact. PNGs are readable pictures, not editable backups.
- Fixed a pre-existing crash from late mouse/keyboard input after the emulated
  Mac core stopped.
