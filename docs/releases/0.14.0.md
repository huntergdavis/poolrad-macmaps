# 0.14.0 — Your adventure journal, within reach

- Add an offline illustrated journal reader under **Info → Journal**: 58 journal
  entries, 18 proclamations and 23 tavern tales, with 14 original illustrations
  and a local number keypad that never covers the running game.
- Import your own reference book once from the supported Macintosh documents.
  `tools/prepare-journal.py` reads those exact files and their resource forks
  read-only, and refuses to overwrite an existing book.
- Remember the 20 most recent lookups and per-notebook bookmarks. An invalid or
  truncated book is rejected and the previous one is retained.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.14.0/poolrad-macmaps-0.14.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included, and neither is the journal content — the public APK contains
only the reader. The personal bundled APK stays local.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 80.
Same prototype signing key; source tag `v0.14.0`.

**355 Java tests**, 81 Python helper tests and eight Android companion View
checks pass; the public APK asset gate and signature verification pass. Manual
lookups are not automatically encountered references, and journal history is
not yet part of notebook exports. No new physical e-ink or stylus acceptance
was performed for this reader.
