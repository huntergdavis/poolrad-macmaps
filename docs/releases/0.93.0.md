# 0.93.0 — Skip autosaves with nothing new to protect

F103: the five-minute autosave now checks whether anything has happened since
the last snapshot before paying for a capture, compression and a disk
fingerprint. A guest key or mouse press, a change in the party, map or
message readings, or a disk write or mount change all count as activity; a
tick with none since the last successful snapshot or completed restore is
skipped and logged. Anything else saves exactly as before, as does a tick
after a failed save, so no real recovery point is lost.

Activity that arrives while a save is still compressing is carried to the
next tick, because the published image predates it. The interval, the
20-autosave rotation and the snapshot format are unchanged.

Validation: 731 Java tests, including the first-save, activity,
input/disk counter, mid-save activity, failure and restore cases; universal
Mac II build; live emulator acceptance in docs/SAVE_STATES.md. No
physical-device battery measurement is claimed.
