# 0.16.0 — Your journal, kept with your notes

- **Journal history now belongs to the notebook.** Lookups, bookmarks, your own
  checked tasks and your flag links live in the notebook's own record and are
  included in its backup and restore. 0.14.0 kept them in app preferences, where
  a backup silently lost them.
- Any history 0.14.0 left behind moves into the selected notebook once, the
  first time that notebook is opened. The old preference keys are removed only
  after the notebook record is safely stored.
- **Check off a bookmark** as your own task. This records your judgement, never
  a quest the original game reports as finished, and only a bookmark can be
  checked off.
- **Link a reference to a map flag you placed**, so that flag's handwriting
  becomes the reference's comment. The handwritten page gains a **Journal**
  action in its existing scrolling tool row, showing how many references point
  at that flag. Deleting a flag drops its links and leaves other references
  alone. Links never reveal an unvisited place or mark anything as discovered.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.16.0/poolrad-macmaps-0.16.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included, and neither is the journal reference book — keep your `.prjr`
file for reimport. The personal bundled APK stays local. No game rules, stats,
save formats, notebook identities or handwriting formats change.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 82.
Same prototype signing key; source tag `v0.16.0`. Back up notebooks before
uninstalling or clearing app data; update in place to retain them.

**377 Java tests** and **6 Android software-Canvas checks** for the compact note
editor pass, as do the public APK asset gate and signature verification. The
drawing sheet keeps the exact height 0.13.0 gave it, measured at 1200×1600.
A damaged journal record refuses export rather than backing up an empty history,
and is never silently replaced.

Verified on the isolated test emulator by updating a notebook that really did
carry 0.14.0 preference history: the preference keys disappear, the notebook
record decodes to exactly the same three lookups and one bookmark, and checking
off and linking survive a guest reload. Notebook export and restore of that
record were exercised through the real store code in tests rather than through
the Android document picker on device. Physical e-ink and stylus acceptance of
the Journal action is untested.
