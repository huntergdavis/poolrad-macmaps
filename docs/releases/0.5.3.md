# 0.5.3 — Pen-friendly map notes

- Optional **Pen only**, remembered between pages and launches.
- Pinch to zoom up to 4×; drag with two fingers, or one in pen-only mode.
  **Fit page** restores the full map-and-writing sheet without changing ink.
- Recognized pen/eraser input, palm-pointer isolation, and canceled-stroke
  protection. Finger drawing remains available by default.
- Nearby flags offer larger choices without silently creating a new note.
  Toolbar buttons retain readable touch sizes; note dialogs do not fade or slide.

170 Java tests, three native suites, 13 synthetic Android pen-input checks,
six composite-sheet checks and seven party-pane View checks pass. The update
preserves the existing handwritten note and its migration backup exactly.

**Physical stylus, palm rejection quality and e-ink behavior are untested.**
N3 remains open for that device check; notebook backups are the next software
slice. [Pen controls and acceptance checklist](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/PEN_NOTES.md).
Forced emulator display-size changes rebooted the guest; seamless window
resizing is not established. [Test evidence and limits](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/LOCAL_TESTING.md#053-pen-note-software-acceptance-2026-09-14).

Install `poolrad-macmaps-0.5.3.apk` **over your existing app**, not by uninstalling.
Android 5.0+, Mac II, ARM64/ARMv7/x86/x86_64; versionCode 70, same prototype
signing key. Bring your own matching ROM, system disk and game; none are bundled.
[Install guide](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/INSTALL.md).
