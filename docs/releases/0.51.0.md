# 0.51.0 — Older footprints, drawn smaller

A trail of identical prints says where you have been and nothing about the
order. A corridor walked twice looked like one walked once; a dead end looked
like a through route.

Older prints are now smaller, which puts the order back without adding a second
kind of mark. Walk over a square again and its print becomes the newest.

**Shrinking rather than shading**, because shading does not survive e-ink — at
this size a light grey and a dither pattern are the same thing. A smaller print
is smaller at any contrast.

**The range is narrow on purpose.** The oldest print is about three-quarters of
the newest: a gradient when you look for it, an ordinary trail when you do not.
A wider spread would turn the earliest steps into specks, and those are still
squares the party walked.

## Two rules the checks insisted on

- **Standing still changes nothing.** An anchor is an observation with no
  movement behind it. The drawing already refuses to let one invent or erase a
  footprint; letting one advance the ages would quietly resize every print on
  the map for standing still.
- **A square with no recorded step is drawn full size**, not smallest. Being
  unsure how old something is is not the same as knowing it is old.

**Verified:** 557 Java tests including nine new ones, six native probe suites,
55 render checks across four suites. The new render check measures ink on the
tiles themselves rather than a scale factor, so it is the drawing being checked
and not the arithmetic.
