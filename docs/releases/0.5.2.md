# 0.5.2 — Party health through combat

The health strip now distinguishes your party from enemies sharing the Mac
game's character list. All six heroes remain visible in a real kobold battle,
with names, current/max HP and dark bars in the original party order.

- Real combat injuries and a last-to-first party reorder verified in the game.
- Normal healing changes Arax from 7/12 to 12/12 and fills the matching bar.
- Saved injured party reopens correctly after installing the update.
- 152 Java tests, three native sanitizer suites and seven actual Android
  health-pane rendering checks pass, including narrow layouts and empty bars.
- Existing handwritten notes and their migration backups remain byte-identical.

Install `poolrad-macmaps-0.5.2.apk` **over the existing app** to retain notes.
Android 5.0+, Mac II, ARM64/ARMv7/x86/x86_64; versionCode 69, same prototype
signing key. [Setup guide](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/INSTALL.md).

Bring your own matching ROM, system and game; none are included. This remains
an experimental prerelease. Full-game mode recognition, notebook backups and
physical e-ink/stylus acceptance remain on the backlog. Health is cleared when
its memory sample is unavailable, never guessed.
[Validation details](https://github.com/huntergdavis/poolrad-macmaps/blob/main/docs/PARTY.md).
