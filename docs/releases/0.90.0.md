# 0.90.0 — Count fights and spells since the last rest

F59 adds **Info → Since last rest**, beside Saves. It shows when the party
last rested by the game's own clock, how many hours it rested and how much game
time has passed, then the fights fought and spells cast since. Before any rest
it says it is counting since the game was loaded.

Everything is read from what the game already publishes: a fight begins when
the mode turns to combat; a cast empties one of a character's ready memorized
spell slots; a rest is an hour of camp time, or chosen spells finishing
memorizing. A rousted five-minute rest does not count. Nothing in the guest
changes.

The tally is saved beside every snapshot and comes back when one is loaded,
so a restored machine reports its own count. A load starts the count over.

Validation: 719 Java tests covering fights across unreadable frames,
casts versus memorize/reset movement, hour and memorization rests, rousted
rests, wilderness travel, clock rewinds, load screens and the sidecar round
trip; universal Mac II build. Live on the sandbox emulator: the fresh-load
page, memorize-is-not-a-cast on the page, and fights, completed and rousted
rests read in the tally log across three Slums fights. Spells cast were not
exercised live because this build's rests emptied chosen slots instead of
memorizing them. The Quick toggle path gained step logging; mid-combat taps
wrote immediately in every logged fight. See docs/SINCE_LAST_REST.md.
