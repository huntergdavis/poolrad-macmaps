# 0.91.0 — Redraw combat only when it changes

An unchanged combat reading no longer redraws the map or rebuilds its
accessibility description. Movement, acting turns, fallen markers, enemy names
and counts still refresh immediately; health updates retain their independent
change check. Polling and the existing protection against briefly unreadable
frames are unchanged.

Verified in a real emulator fight, including movement, damage, fallen markers
and turn changes. A quiet turn received 10 accepted updates with zero map
draws. All 722 Java tests and 19 Android combat rendering checks pass.
