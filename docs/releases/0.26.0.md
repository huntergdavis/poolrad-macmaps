# 0.26.0 — Proclamations and entries join the list too

- The notebook's **Encountered in play** list now also collects the
  **proclamations** the game posts and the **journal entries** it tells you to
  copy down, alongside the tavern tales it already gathered.
- Proclamations are cited in Roman numerals, as a list — walk past the city
  hall walls and all of them land in the notebook at once, in the order the
  game named them, each tappable straight into your reference book.
- Only the eighteen proclamation numerals the journal actually defines are
  recognised, so an unfamiliar one is skipped rather than turned into some
  other number.
- **One honest limitation:** the journal-entry wording is matched from a
  screenshot of a different port of the game, not of the supported Macintosh
  version. If the Macintosh build words it differently, nothing is recorded —
  the pattern cannot invent a number, it can only stay quiet.

Nothing is written to the game, and no reference is opened for you; the list
only remembers what the game already said in front of you.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.26.0/poolrad-macmaps-0.26.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. Journal content is not included in the public APK.
