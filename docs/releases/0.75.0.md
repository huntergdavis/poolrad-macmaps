# 0.75.0 — Publish the Macintosh save-format specification

F80 publishes the verified original-game save format: exact data-fork blocks,
PoRc character/inventory/effect framing, save-time packing, Macintosh metadata,
and the MacBinary/PRSV wrappers. It corrects the early overview's approximate
block boundaries and documents the full two-byte item count.

The specification distinguishes verified structure from unresolved field
semantics and cross-platform conversion work. It includes validation rules,
references to the writer and synthetic tests, and the original game's successful
load/character round-trip evidence. No game data, assets or disks are shipped.

The six save-writer synthetic tests pass. This is a documentation release;
Android behavior is unchanged.
