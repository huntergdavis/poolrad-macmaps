# 0.63.0 — A legend for the map's marks

**A key to every mark the companion draws**, because they have piled up and
e-ink has no colour to lean on. Open **Info → Map legend**.

Each entry draws the actual mark beside what it means, so the key looks like the
thing it explains:

- **On the map:** the party arrow, an unwalked-exit chevron, a struck-through
  "fight here", your note flag, footprints, and fog of war.
- **In a fight:** your filled circle, an open-square foe, the diagonal cross for
  someone down but still savable, the upright cross for dead or petrified, and
  the ring for whose turn it is.
- **On the party rows:** Q (quick), T (can train), R (awaiting rest), W (slowed
  by load), and the bar that marks who is acting.

It is reference only — it reads nothing from the game and changes nothing.

**Verified:** 607 Java tests, the native build, the APK ABI check, and a live
run opening the legend and scrolling through every mark.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.63.0/poolrad-macmaps-0.63.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
