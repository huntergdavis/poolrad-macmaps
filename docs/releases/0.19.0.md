# 0.19.0 — What you are holding, and room to see it

- **Readied weapon and armor** in character details, under the game's own item
  names, composed the way the game composes them. An empty hand reads *No weapon
  readied*; item data the app cannot read reads *unavailable* and never pretends
  the hand is empty.
- **Movement and carried weight**, in combat squares and gold-piece weight, with
  one warning only when the game's own movement has already reached the slowest
  the printed rules describe. These are plain character fields, so they keep
  working even when the item data does not.
- Nothing here equips, unequips or changes an item. **Ammunition is not
  reported** — that part of the feature was conditioned on being verified, it
  has not been, and the details pane says so rather than guessing.
- **The map caption is one line instead of two.** The standing
  "North up · N walked" reminder is gone and the height goes to the map, so the
  grid is genuinely larger. The remaining line still carries the camp/loading
  explanation or exploration status when there is one, plus the notebook name.
- **An eight-member party no longer loses its sidebar.** With NPCs a party can
  reach eight, which did not fit one column at tablet height — the whole party
  strip used to disappear at exactly the point you have the most to track. It
  now falls back to two columns, taking the width from the map, so every row
  stays as tall and as wide as a short party's.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.19.0/poolrad-macmaps-0.19.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. No game rules, stats, save formats, notebook identities or
handwriting formats change, and nothing is written to guest memory.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 85.
Same prototype signing key; source tag `v0.19.0`.

**407 Java tests**, the rebuilt native party-probe suite and **23 Android
software-Canvas checks** pass, as does the public APK asset gate.

Verified live against the game's own character sheet: where the game printed
Weapon: Long Sword and Armor: Banded Mail, the companion read the same, and
before the game had loaded that item data the same pane honestly said
unavailable. The single-line caption and the larger grid were confirmed on the
running app at 1200×1600.

The **eight-member two-column layout was checked by the Android View harness at
the real device density, not by playing with NPCs in the party**, since the
sample party has six. No physical e-ink, stylus or tablet acceptance is claimed.
