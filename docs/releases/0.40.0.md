# 0.40.0 — The doors you have not gone through

Your own map now tells you where you have not been. Every door the party has
stood beside and never walked through gets a small chevron pointing out of it,
into the square nobody has visited.

- It reads **only squares you have already walked**, so it spoils nothing. The
  other thing it knows — that you have not been through — is your own trail.
- **Doorways only, not open edges.** The frontier of an explored region is
  mostly open corridor; marking all of it would mark every unfinished passage
  rather than the handful of doors worth remembering.
- **Not doors in the outer wall.** Those leave the area, so there is no square
  beyond them to have visited, and they would stay marked however many times
  you used them.
- A chevron because nothing else on the map is one — walls are lines, a doorway
  is a break in them, footprints are soles, walked squares are corner dots. It
  points, which is the whole message.
- Below the size where it would be a smudge rather than an arrow it is not
  drawn. The count is in the accessible text either way: "3 doors not yet gone
  through."

There is **no switch for it yet**. When the options page lands it will get one
alongside the fog and footprints.

**Verified:** 473 Java tests including eight new ones, five native probe suites,
and 25 render checks across three suites — the new one measures the mark
against the same map with a plain wall in the door's place, so the doorway
symbol cancels out and what is left is the mark itself. Not verified here:
e-ink, stylus or on-device acceptance, which remain the owner's own.
