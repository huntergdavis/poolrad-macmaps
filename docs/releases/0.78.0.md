# 0.78.0 — Open the reference the game just named

F42 replaces the journal's transient citation toast with a retained notice
inside the companion. Tap it to open the exact newly cited entry. When a
message names several references, choose among just those references.
Dismiss clears it; switching notebooks or starting a snapshot load also clears
it. Repeated readings of an already encountered reference do not nag.

The notice stays above the guest, uses monochrome buttons and does not take
keyboard focus. Existing citation recognition and journal history are preserved.

The universal build and 646 Java tests passed. Nine Android companion checks
cover layout, accessibility and actions. Isolated host-message replay verified
direct Tavern tale 15 opening and the four-reference chooser with exact
Proclamation 78 opening. These were UI fixtures using verified wording, not
newly played encounters. No physical-tablet retest is claimed.

Repeated debugger setup is now shared by the existing guest-command helper and
a notebook-guarded message-replay helper. See docs/CITATION_NOTICE.md.
