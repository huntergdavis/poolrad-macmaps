# 0.27.0 — The party always shows, and the journal comes with it

- **The party pane no longer disappears on high-density screens.** On a tablet
  like the 292 PPI panel this is built for, there was no way to fit the map and
  the party side by side at all — so the party now moves to a strip underneath
  the map instead of vanishing. Wide screens keep the sidebar exactly as before.
- Strip cells are narrower, so they show the class or condition mark, the name,
  hit points and the health bar, dropping the armour class when space is tight.
- **The adventurer's journal is now included with the app.** All 58 journal
  entries, 18 proclamations, 23 tavern tales and the 14 original illustrations.
  There is nothing to import and nothing to prepare: open Info → Journal and
  read, or let the game's own citations collect themselves as you play.

Pool of Radiance is a 1989 game for a long-discontinued machine, and its journal
is the part a player cannot do without — the game prints bare reference numbers
and expects the printed book at your elbow.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.27.0/poolrad-macmaps-0.27.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
those are still not included.
