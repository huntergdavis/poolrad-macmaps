# 0.80.0 — Read the party's marching order

F72 adds **Info → Marching order**, a numbered list of the current party,
first to last. It uses the existing validated roster order and keeps the
map's party rows uncluttered. The page scrolls above the guest, follows updated
party readings, and shows unavailable when the map's retained party reading
clears. Its refresh timer stops on pause and dismissal.

The original game remains responsible for changing the order:
close the page, then use **Encamp → Alter → Order**.

The universal build and all 647 Java tests passed. Nine Android companion
navigation checks passed. Live acceptance compared all six numbered names
with the original party and then checked a real reorder through the game's
own controls. No physical-tablet retest is claimed.

Repeated normal shutdown, APK installation and original-save loading are now
combined in tools/update-test-app.py. Its complete emulator workflow passed,
including closed-disk verification, APK ABI checks and retained load evidence.
