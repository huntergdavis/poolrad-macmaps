# 0.97.0 — Background means idle

Backgrounding the app now puts the emulator to sleep instead of retrying its
paused loop. Guest execution, audio, companion polling and the Wi-Fi multicast
lock stay off until the app returns to the foreground. No new setting.

Resume and explicit pending operations wake the emulator promptly. Rapid
pause/resume requests and pausing during startup preserve the latest lifecycle
state; returning to the game does not replay time spent away.

Verified live: zero emulator CPU time and wake-ups while backgrounded, including
with sound enabled; foreground movement and map updates resume cleanly.
All 736 Java tests and 2,000 native wake-race checks pass.
