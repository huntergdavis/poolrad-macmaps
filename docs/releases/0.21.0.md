# 0.21.0 — The party comes back on a real tablet

- **Fixes the missing party sidebar on the Viwoods AiPaper Mini.** At 1440 px
  wide and a high pixel density, the sidebar's fixed-width column plus the map's
  minimum width needed more room than the panel has, so the whole party strip
  silently disappeared once the party reached four members. The column now
  narrows before the sidebar is ever dropped, and never takes more than 55% of
  the pane.
- Every supported party size from one to eight keeps a sidebar across the
  densities and pane heights that device produces, with rows and columns both
  held above a readable minimum and the map keeping its own floor.
- Where the full-width column already fit, nothing changes.

This was invisible on the development emulator, which runs at a taller, much
coarser geometry than the real tablet. Layout work is now checked against
1440-wide high-density geometry as well.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.21.0/poolrad-macmaps-0.21.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 87.
Same prototype signing key; source tag `v0.21.0`.

The fix is computed and unit-tested across the device's plausible geometries;
it has **not** been seen running on the physical tablet by anyone but Hunter.
