# 0.72.0 — Write original Macintosh game saves

F79 adds a reusable host tool, `tools/write-game-save.py`, that creates an
original-game save from a validated RAM capture. It preserves world state,
characters, inventory and effects, and produces both Macintosh forks,
MacBinary and `.prsv` files. It refuses malformed captures and existing outputs.

The original game loaded a newly generated save on a disposable disk at the
correct position. All six complete character resources, including 34 items
and seven effects, matched byte-for-byte after loading.

This is a command-line writer, not a new Android save menu. Usage, supported
states, loading instructions and evidence are in `docs/SAVE_WRITER.md`.
No ROM, disk, capture, generated save or extracted game code is distributed.

Validation: six writer tests, native suites, 634 Java tests and universal APK
checks passed. Two unrelated Python suites skipped for absent optional modules;
physical-tablet testing was not repeated.
