# 0.73.0 — Show the selected character

F66 marks the game's selected character with a narrow bar in the party pane,
including compact rows. Accessibility names the selection. During combat,
the existing acting-character marker takes precedence.

The read-only probe matches the selected handle against the validated party.
Missing, stale and monster handles produce no selection marker. Legacy packets
remain supported; loading and unavailable states hide the marker.

Live acceptance: Arax → Lara selection moved the bar with the original game's
bolded name; normal and compact layouts both passed. Native sanitizer suites
and 636 Java tests passed. All 16 Android combat/party render checks passed,
including combat actor precedence. No physical-tablet retest is claimed.

Repeated APK testing now has a reusable emulator-only normal-shutdown helper.
It checks the quit/Finder screens, uses Special → Shut Down, and verifies that
disk handles closed before reporting success.
