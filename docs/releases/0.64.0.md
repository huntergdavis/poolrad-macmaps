# 0.64.0 — Boot past the "not shut down" dialog on its own

**If the Mac was not shut down cleanly last time, it no longer stalls on the
startup dialog.** Before this, an unclean shutdown left the machine sitting at
"This computer may not have been shut down properly," waiting for the Return key,
and the game never started until you pressed it. Now the companion presses it
for you.

**How it works:** during the boot window — before a party is in the world — a
screen that has gone still for a few seconds is nudged with a single Return,
through the same path the map's own Return key already uses. A Return at that
point can only dismiss the alert or advance a title card, and it stops as soon
as the game reaches its own copy-protection screen. Small flickers (a blinking
cursor, the menu clock) do not count as movement, so a genuinely still dialog is
recognised as still.

There is nothing to turn on — it just works.

**Verified:** 607 Java tests, the native build, the APK ABI check, and a live
run: after an unclean shutdown the machine cleared the dialog itself and booted
through to the game without a key pressed by hand.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.64.0/poolrad-macmaps-0.64.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
