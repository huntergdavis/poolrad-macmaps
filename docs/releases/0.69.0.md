# 0.69.0 — Back up the whole companion at once

**One file for everything: all your notebooks and your fog-of-war settings
together.** Under **PoolRad → Notebooks**, two new buttons:

- **Back up everything…** writes every notebook (each with its areas, trails and
  notes) and your fog switches into a single file you can keep anywhere.
- **Restore everything…** reads one of those files back.

Restoring keeps each notebook's own identity, so a save state that was paired
with a notebook finds it again. A notebook you already have is left exactly as it
is — restore never duplicates or overwrites an existing campaign.

This is the whole-companion backup; the per-notebook backup and the read-only PDF
export are still there for single campaigns.

**Verified:** 613 Java tests (the backup round-trips notebooks with their notes
and the fog switches, and skips one already present), and a live run — "Back up
everything…" produced a valid archive holding both notebooks and the fog setting.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.69.0/poolrad-macmaps-0.69.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included.
