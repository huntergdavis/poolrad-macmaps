# 0.111.0 — Quick save when a fight starts

The companion now requests a quick save when it first detects a fight starting,
as well as after a fight ends. The snapshot can let you retry from early in
the battle. Detection and saving take time; it does not guarantee a capture
before anyone acts.

Fight-start, fight-end and manual quick saves share the ten newest slots.
**Quick load** restores the newest successful one. Use **Load…** to choose
an older snapshot. [Save behavior and limits](../SAVE_STATES.md#quick-save-when-a-fight-starts-2026-09-20).

Verified live on the emulator: a Slums fight started and `Saved QUICK` landed
within seconds, shown as the active save in Info → Saves; when the fight
ended, the existing fight-end quick save landed as before.
