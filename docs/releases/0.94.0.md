# 0.94.0 — Templates for notebook pages

The note toolbar's optional **Template** button offers a blank grid, ruled
list and blank map frame on the writing half, keeping the area map visible.
Plain paper remains the default. Templates autosave with each page and keep
existing handwriting intact, including through erasing, backups and exports.

Verified live on the emulator with all three templates, drawing, erasing and
save/reopen. All 736 Java tests and 15 Android rendering/layout checks pass.
