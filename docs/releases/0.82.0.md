# 0.82.0 — Show the original game's clock

F48 adds the game's own day and am/pm time to the map header, such as
**Day 1 · 12:10 am**. It follows the original saved counters and advances only
when the game advances time. It never uses Android time or emulator speed.

The clock shares the existing header height with the area and position/combat
summary. Accessibility carries the full reading. Loading clears it; valid camp,
combat and wilderness readings can show time without stale local coordinates.

PRM6 adds eight bytes to the map packet. Native code checks the state allocation,
original unit table, display mode and counter ranges. Older packets keep their
existing behavior without an invented clock. No guest data is written.

Validation: 657 Java tests; native sanitizer tests across counter ranges,
invalid allocations, modes and unchanged guest RAM; 17 Android rendering checks.
The installed feature showed midnight as 12:00 am and followed an original-game
Look to 12:10 am. No physical e-ink or real day-rollover acceptance is claimed.
See docs/GAME_CLOCK.md for the original-code evidence and supported counter range.

The reusable clean-update workflow also now handles a verified Finder desktop
and retries OCR with the alternate layout when sparse OCR splits a menu label.
README screenshot age is checked before publication.
