# 0.13.1 — Walls where walls belong

- Fix phantom wall/door outlines on open edges. The original Macintosh game
  ignores door bits when an edge has no wall surface; the companion now does too.
- Keep doorway symbols neutral: no guessed locked, secret or passable labels.
  The fix is shared by the live map, visited-only view and flag-note maps.
- Record the user's successful physical e-ink testing: stylus drawing and
  two-finger zoom/scroll work well. Rotation, keyboard layout and vendor-specific
  pen behavior remain separate, unreported checks.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.13.1/poolrad-macmaps-0.13.1.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. The personal bundled APK stays local. No game rules, stats,
save formats, notebook identities or handwriting formats change.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 79.
Same prototype signing key; source tag `v0.13.1`. The adjacent `.sha256`
verifies the public download. Back up notebooks before uninstalling or clearing
app data; update in place to retain them.

Public and personal builds, **346 Java tests** and **10 focused Android
software-Canvas checks** pass. Auditing all 29 private maps finds 88 directional
edges with unused door bits; those are source-data counts, not a full-game
playthrough. Original-game checks cover a blocked ivy wall, an open street,
a wooden doorway and Sune's temple entrance. Live locked/secret-state changes
and other areas are not claimed. No native reader code changed in this patch.
The final in-place install preserves the writable disk, handwriting and both
areas' exploration files byte-for-byte; cold boot and saved-party reload restore
the live map, footprints and all six correct HP/AC rows.
