# 0.20.0 — Quieter, and smaller

- **The map header stops flashing.** It used to flip between *Updating*,
  *Loading / setup* and *Position unavailable* several times a second while the
  game settled, inverting to white-on-black for some of them. It now shows one
  steady *Position unavailable* until a real position arrives.
- **The helper-state captions are gone.** The centred "No verified game position
  is available…" line and the standing status caption under the map were
  describing the companion's internal state, not anything the player needed.
  The caption line now says only which notebook is open and that taps work.
  The full reason is still in the accessibility description for screen readers.
- **Disk checkpoints and Mac desktop appearance are removed.** Both could only
  run with the guest shut down. Neither can be made instantaneous safely —
  copying or rewriting a volume the emulator is actively writing gives a torn
  image — so they are gone rather than left as menu entries that mostly refuse.
  Their stores, dialogs and tests are deleted; nothing else loses a feature.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.20.0/poolrad-macmaps-0.20.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
none are included. No game rules, stats, save formats, notebook identities or
handwriting formats change.

Mac II universal, Android 5.0+, ARM64/ARMv7/x86/x86_64, versionCode 86.
Same prototype signing key; source tag `v0.20.0`.

If you were relying on a checkpoint you already took, the files are still in the
app's private storage; this release simply no longer offers a way to make or
restore one. Notebook backups are unaffected and remain the supported way to
keep your handwriting, flags, walked tiles and journal history.
