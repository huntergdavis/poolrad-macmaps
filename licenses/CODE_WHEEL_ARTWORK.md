# Code-wheel artwork attribution

The 72 small GIFs in `android/minivmac/src/main/assets/codewheel/` are unchanged
reference illustrations downloaded from
[Dave Kennedy's Pool of Radiance code wheel](https://dkennedy.io/por-code-wheel/wwm.html)
(`img/esp01.gif`–`esp36.gif`, `img/det01.gif`–`det36.gif`). That reference credits
Andrew Schultz for the lookup work. The existing rune numbering is preserved.

They are bundled here at the project owner's request so building and using the
helper does not depend on another website. The illustrations originate with
the original game's code wheel; all underlying artwork rights remain with
their respective owners. We do not claim authorship or an additional
open-source license for these images. This attribution is not a grant of
rights beyond those held by the original rights holders.

The emulator's GPLv2 and Gold Box Explorer's MIT notices apply to their
respective code, not automatically to third-party game illustrations.
