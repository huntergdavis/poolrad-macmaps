# 0.99.0 — Bandage the dying and quick-save when a fight ends

F40: when a fight ends and someone is still standing, the companion does what
a player would do first. Every character the game left **Dying** is bandaged:
Unconscious at zero hit points, exactly the game's own Bandage result, and
nothing more. Then one quick save is taken so the moment after the fight is
protected, whether or not anyone needed bandaging. A short notice says how
many were bandaged.

This is the project's second write into the running game, authorised in
DESIGN.md. It walks the roster with every check the party reader makes,
touches two bytes for a Dying character and none for anyone else, and refuses
whenever the party does not read cleanly. The readers stay read-only.

Validation: 739 Java tests; the native party test proves a Dying member
changes exactly two bytes of RAM, an Okay or already Unconscious member
changes none, and every refusal writes nothing, under the sanitizers;
universal Mac II build; live emulator acceptance in docs/PARTY.md.
