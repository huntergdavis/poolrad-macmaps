# 0.89.0 — Peek through a discovered exit

Stand on an exit your party has used to see a small preview of its destination
beside the current map. It shows only squares that campaign has already
explored, regardless of the main map's full-map setting. An arrival ring shows
where that passage led. If an exit has several recorded destinations, tap the
preview to browse them.

Remembered maps travel with notebook backups. Existing notebooks fill in their
previews when those areas are revisited. No undiscovered connections or hidden
map cells are revealed.

Verified in the real game on the emulator: the preview appears on the known
exit before crossing and disappears one square away. All 708 Java tests and
15 Android rendering checks pass, including hidden-geometry pixel checks.
