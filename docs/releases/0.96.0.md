# 0.96.0 — Say how spells actually get memorized

A report that resting clears a character's chosen spells was reproduced with
RAM captures and traced in the original game's code. It is the game's own
rule, not the companion's: entering or leaving camp forgets chosen spells, the
timed Camp → Rest never sets the rest-hours byte and so never memorizes, and
only **Magic → Rest** computes the needed time (four hours plus fifteen minutes
per spell level, six hours with a level-3 spell) and memorizes. The companion
writes none of these bytes.

What was wrong on our side was the reminder under a character's awaiting
spells, which said any rest would finish them. It now reads: "To memorize
these, use Magic → Rest in this camp. The timed Camp → Rest does not memorize,
and leaving camp forgets them."

Validation: 736 Java tests; universal Mac II build; RAM captures before
and after each step on the disposable emulator; the code sites are listed in
docs/SPELL_READINESS.md. A completed Magic → Rest with its "has memorized"
message was not watched live in this session.
