# 0.29.0 — When the party will not show, the map says why

The map pane has room for the party and draws it correctly — the caption in
0.28.0 proved that. What it also proved is that the part of the app that reads
the party out of the running game is refusing, and it had no way to say why.

It walks Pool of Radiance's own list of characters and stops the moment anything
does not check out. There are fourteen separate checks, and from the outside all
fourteen looked the same as "no game is running".

- **Each refusal now names itself in the caption**, with how far down the list
  it got and the value it rejected — for example
  `party: heap block rejected after 2 links [82000140]`.

Nothing about what the app is willing to read has changed, and nothing new
leaves the game: a reason, a count, and one memory-structure value.

If your party does not appear, walk one step so the map is live, screenshot the
top pane, and the caption will say exactly which check refused.

[Download the public APK](https://github.com/huntergdavis/poolrad-macmaps/releases/download/v0.29.0/poolrad-macmaps-0.29.0.apk)
and install over the existing app. **Bring your own ROM, Mac system and game**;
those are still not included.
